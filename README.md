# HNG-FRONTEND-STAGE-0
HNG Frontend Stage 0 Project - A Profile Card

A simple responsive Profile Card built using vanilla HTML, CSS and JS

## Live Demo
[Hosted on Netlify](https://hng-frontend-stage-0.netlify.app/)

## Project Structure
```
HNG-FRONTEND-STAGE-0/
├── index.html
├── styles.css
└── image/
    └── profile.jpg
```
    
## Installation
Clone this repository:
```bash
  git clone git@github.com:Lufi-SAN/HNG-FRONTEND-STAGE-0.git
```
Open Project Folder:
```bash
  cd HNG-FRONTEND-STAGE-0
```
Open index.html in your browser
